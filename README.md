# Financial Statement Analysis

## Project overview
Explore a fictional company's financial statements and calculate key profitability, liquidity and leverage ratios.

## Objective
Build practical business and finance analytics skills by cleaning, summarising and interpreting a structured dataset.

## Tools used
Python, pandas, Excel

## Repository structure
- `data/` — sample dataset used in the analysis
- `src/analysis.py` — Python analysis script
- `README.md` — project documentation
- `requirements.txt` — Python libraries required

## How to run
1. Install Python 3.10 or later.
2. Install the required libraries:
   ```bash
   pip install -r requirements.txt
   ```
3. Open a terminal in this project folder.
4. Run:
   ```bash
   python src/analysis.py
   ```

## Dataset note
The included data is synthetic and created for learning and portfolio demonstration. It does not represent a real company, customer, investor, or live market feed.

## What to explore
- Check the dataset for missing values and unusual observations.
- Recreate the analysis in Excel using formulas, PivotTables and charts.
- Add your own interpretation of the results.
- Extend the project with additional metrics and visualisations.

## Key learning outcomes
- Working with tabular data
- Basic financial/business analysis
- Summarising findings clearly
- Documenting a reproducible analysis workflow

This repository is an educational portfolio project. It is not financial, investment, or business advice.
